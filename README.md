# QA Test Cases: SauceDemo

Manual test cases for [SauceDemo](https://www.saucedemo.com), a public practice shop website made for testers.
The login details for the practice users are shown on the site's own login page.

## What's inside
| File | Purpose |
|------|---------|
| `test_cases.csv` | 15 test cases covering login, products, cart, checkout, logout and a basic access check |
| `bug_report_template.md` | The format I use to report a bug |

## How I tested
1. Read the site and listed its features.
2. Wrote test cases with clear steps and expected results.
3. Ran each test and recorded the actual result and status (Pass / Fail).
4. Wrote a bug report for every failure.
